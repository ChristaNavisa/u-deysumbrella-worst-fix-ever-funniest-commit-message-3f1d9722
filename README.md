Entry for [Worst Fix Ever: Funniest Commit Message](https://make.fun/c/u-deysumbrella-worst-fix-ever-funniest-commit-message-3f1d9722) on make.fun.

`main.ts` writes a single commit message — a bug fix that made everything
worse — to `/output/entry.txt`:

> fix: typo in README, deleted production database instead

One line, 56 characters, a tired engineer fixing a typo in the README and
accidentally deleting the production database instead. The program checks
the 1–100 character gate itself before writing, and writes the same bytes
on every run.
